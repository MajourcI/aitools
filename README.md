# Texto — бесплатные AI‑инструменты для текста и учёбы

Набор бесплатных инструментов на русском, работающих на базе ИИ: генератор рефератов и
эссе, гуманайзер, рерайт, сокращение, идеи для контента, улучшение резюме, распознавание
текста с фото (OCR), чат, вопросы по тексту и проверка на признаки ИИ.

🌐 **Прод:** [majourci.online](https://majourci.online) — деплоится автоматически из ветки `main`.

## Стек

- **Backend:** Node.js + Express (`server.js`) и модули роутов `routes_study.js`, `routes_ocr.js`.
- **Frontend:** статические HTML‑страницы в `public/` + общий дизайн `study.css` и утилиты `util.js`.
- **Модели (через Groq API):** `llama-3.3-70b-versatile` для текста, `llama-4-scout-17b` со зрением для OCR.
- **Генерация однотипных страниц:** `build_pages.py`.

## Структура

```
server.js          — Express‑сервер, /api/tool (гуманайзер, рерайт, сократить, резюме, идеи), счётчик, защита
routes_study.js    — /api/ask (вопросы по тексту), /api/generate (генератор), /api/chat (стриминг), чистые URL
routes_ocr.js      — /api/ocr (распознавание текста с фото)
build_pages.py     — генератор страниц инструментов
public/            — фронтенд
  ├─ index.html      — главная
  ├─ study.css       — общий дизайн (светлая/тёмная тема, переиспользуется всеми страницами)
  ├─ util.js         — экспорт (Word/PDF/txt) и автосохранение черновиков
  ├─ *.html          — страницы инструментов
  ├─ sitemap.xml, robots.txt, favicon.svg, og-cover.png
```

## Запуск локально

```bash
npm install
GROQ_API_KEY=... node server.js   # http://localhost:3000
```

### Переменные окружения

| Переменная      | Назначение                                              |
|-----------------|---------------------------------------------------------|
| `GROQ_API_KEY`  | Ключ Groq API (обязательно).                            |
| `PORT`          | Порт сервера (по умолчанию `3000`).                     |
| `STATS_BASE`    | Базовое значение публичного счётчика обработанных текстов. |

> Секреты (`.env`, `GROQ_API_KEY`) в репозиторий не коммитятся — см. `.gitignore`.

## Деплой

Любой коммит в `main` автоматически попадает в прод на [majourci.online](https://majourci.online).
Поэтому перед пушем код проверяется, чтобы рабочий сайт не падал.

## Безопасность

- CORS закрыт на свои домены, есть rate‑limit по IP и honeypot против ботов.
- Тексты пользователей не сохраняются на сервере — обрабатываются на лету.
